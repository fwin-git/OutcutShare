# Hotkeys

All shortcuts work **system-wide** while Outcut Share is running — no extra
permissions needed. Configure them under *Settings → Shortcuts*.

## Defaults

| Action | Default |
| --- | --- |
| Select Region & Share | ⌃⌥⌘S |
| Share Last Region | ⌃⌥⌘L |
| Move / Resize Region | ⌃⌥⌘M |
| Pause / Resume Sharing | ⌃⌥⌘P |
| Start / Stop Recording | ⌃⌥⌘R |
| Stop Sharing | ⌃⌥⌘X |
| Share preset 1–9 | ⌃⌥⌘1–9 (fixed) |

## Recording a shortcut

Click **Record**, press any key combination, done. Esc cancels recording;
**✕** removes a binding entirely (and stays removed across launches).
Any combo is allowed, including single keys.

## Warnings

- **Duplicates:** assigning the same combo to two actions shows an orange
  warning on both rows and names the other action. Only the first action (in
  menu order) stays active until you resolve the conflict.
- **Bare keys:** a combo without modifiers (except F-keys) gets a caution —
  it would swallow that keystroke in every app.
