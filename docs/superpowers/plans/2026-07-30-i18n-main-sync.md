# Internationalization Main-Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge the latest `main` into `feature/i18n-localization`, preserve all upstream showcase behavior, and make every incoming production feature locale-safe for English, German, French, Spanish, Simplified Chinese, and Japanese.

**Architecture:** Use a real merge commit, combining `main`'s behavior with the feature branch's typed localization calls and bundle/catalog gates. Replace the incoming demo choreography's dependence on localized help text with stable internal `DemoControlID` values, while visible help text continues to come from `L10n`.

**Tech Stack:** Git merge, Swift 5, AppKit, SwiftUI, Foundation, XCTest, Apple String Catalogs, `xcstringstool`, Make.

## Global Constraints

- Supported locale identifiers remain exactly `en`, `de`, `fr`, `es`, `zh-Hans`, and `ja`.
- English remains the development language and complete fallback.
- Preserve both the upstream demo/showcase milestone and every localization commit.
- Localize all incoming production-facing UI; debug CLI output and demo-only fake content remain untranslated.
- Demo automation must identify controls with stable technical IDs, never English or translated labels.
- Do not change persisted raw values, URL protocol values, bundle identifiers, filenames, debug flags, or user-authored content.
- Preserve Swift 5 language mode, macOS 14 minimum deployment, stable Apple Development signing, and zero build warnings.
- Work only on `feature/i18n-localization`; do not push, release, or merge into `main`.

- [ ] **Step 3: Add the stable technical identifiers**

Create `DemoControlID.swift`:

```swift
enum DemoControlID: String, CaseIterable {
    case hotbarScreenshot = "hotbar.screenshot"
    case hotbarRecording = "hotbar.recording"
    case captureImage = "capture.image"
    case captureTimeline = "capture.timeline"
    case captureTrim = "capture.trim"
    case captureSaveTrimmedCopy = "capture.saveTrimmedCopy"
}

struct HotbarRecordingPresentation {
    let controlID = DemoControlID.hotbarRecording
    let help: String

    init(
        isRecording: Bool,
        bundle: Bundle = .main,
        localeIdentifier: String? = nil
    ) {
        help = L10n.string(
            isRecording ? .menuStopRecording : .menuStartRecording,
            bundle: bundle,
            localeIdentifier: localeIdentifier
        )
    }
}
```

These values are an internal cross-component protocol and must not be
localized.

- [ ] **Step 4: Key demo anchors by stable IDs**

In `CaptureResultPreview.swift`, key image, timeline, trim, and save-chip
