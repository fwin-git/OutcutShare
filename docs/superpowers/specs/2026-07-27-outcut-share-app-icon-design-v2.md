# Outcut Share App Icon Design V2

Date: 2026-07-27

## Goal

Replace the first Outcut Share icon study with six fresh PNG concepts based on
the visual grammar of the six user-provided reference icons.

The references are style and composition inputs only. The generated artwork
must remain original and must not reproduce a reference icon's exact glyph,
layout, or distinctive details.

## Reference Roles

- Image 1: style reference for a warm enclosure, dark inset, crop brackets,
  and compact centered detail.
- Image 2: style reference for a colorful foreground screen plane and a simple
  cursor interaction.
- Image 3: style reference for a luminous foreground panel with quiet stacked
  outlines behind it.
- Image 4: style reference for a single bold abstract ultrawide silhouette.
- Image 5: style reference for a small screen nested in a graphite enclosure
  with a simple action badge.
- Image 6: style reference for overlapping source and selected panels with
  strong color separation.

## Shared Visual Language

Every concept must use:

- a front-facing, compact app-icon composition;
- one rounded-square or softly rounded enclosure that fills the canvas;
- one bold centered metaphor made from two to five large shapes;
- controlled color with one dominant palette and one accent;
- gentle bevel or translucent depth, not a glossy object floating in space;
- no isometric scene, pedestal, cast floor shadow, deep ambient void, or
  cinematic lighting;
- no text, letters, numbers, logos, trademarks, or watermarks;
- a strong silhouette and clear contrast at 64 × 64 pixels;
- original artwork that evokes Outcut Share's region-selection and
  region-sharing purpose.

The output is a flattened 1024 × 1024 PNG concept set. It is not an Icon
Composer source file and does not modify the application bundle.

## Concept 1: Focus Frame

A warm amber enclosure contains a dark cocoa inset. Four chunky cream crop
corners surround a small focus point made from a dot and four short ticks. It
communicates region selection in the simplest possible form.

## Concept 2: Cursor Lift

A soft pearl enclosure holds a compact monitor base. A saturated
magenta-to-violet rectangular screen plane lifts slightly forward while one
slender pointer cursor crosses its corner. The shapes stay front-facing and
simple rather than becoming a monitor product rendering.

## Concept 3: Shared Pane Stack

A violet enclosure contains one luminous pale foreground pane with two quiet
translucent pane outlines behind it. A small rectangular notch or highlight on
the foreground pane suggests that one region has been pulled forward for
sharing.

## Concept 4: Convex Window

A gold-to-umber enclosure contains one bold cream ultrawide glyph whose outer
silhouette bows outward at the center. A smaller straight rectangular opening
inside the glyph represents the selected region. The result is a memorable
single symbol, not a literal monitor illustration.

## Concept 5: Region Out

A graphite enclosure contains a small straight screen with a bright
cyan-magenta selected region. One compact downward-and-outward action arrow
sits inside the selected region. The arrow must remain secondary to the screen
and must not read as a generic download-app icon.

## Concept 6: Split Selection

A blue-gray enclosure contains two overlapping rounded panels: a muted source
panel and one bright cyan selected panel shifted forward. Three tiny neutral
dots may appear on the selected panel as abstract content, but there is no
window chrome or text.
