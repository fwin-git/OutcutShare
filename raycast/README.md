# Outcut Share — Raycast extension

Raycast commands for Outcut Share (share region/preset, stop, pause,
record, follow & share modes, presenter toggles), talking to the app via
its `outcutshare://` URL scheme.

Load it: `npm install && npm run dev` (needs Raycast + Node ≥ 20; stays
installed after quitting the dev server).

Full docs: [../docs/raycast.md](../docs/raycast.md)
